# 论证链实验室

当前源码应用与题库为 **1.3.0**。修复续答、跨题回退、反方指代、修改不确定、理由错接和参考覆盖指标，并把实际判断边界放在结果首页。发布与验收边界见 `docs/RELEASE-1.3.0.md`；`npm run test:release` 执行单元检查、生产构建和真实浏览器回归。源码版本不等于线上已更新。

一个不要求注册的中文政策论证工具。先说明题设、固定条件和完整方案，再逐题判断；通过比较完整修改方案，记录哪些差异足以改变本轮判断。每个步骤只提出一个主要问题，不推断永久政治身份。

## 1.3 问卷

初始答案仍然只有 `应当 / 不应当 / 不确定`。不接受完整原方案后，一次比较一个完整修改。接受修改只说明这个修改足够，不代表它是必要条件、最小组合或最偏好的方案。

进行中题目从题目列表原位继续；切换题目、刷新和本题回退不会覆盖其他题目。已完成的题目可以回看小结；清除本题并重新回答是需要确认的独立操作。

不确定的原因可以选填并保存；对一个修改不确定后，可以保留该记录，再比较后续修改。不确定和未测试都不等于拒绝。主要理由可以先记录为“尚未检验”，随后从原处继续检查，不能把省略的前提或案例算作通过。前提不接受、原则不接受以及原则不适用，保留为不同的未确认尝试。

正式模型包含 13 项政策、53 个维度、63 个完整框架、50 个诊断节点、199 个命题和 306 条理由定义；其中 4 条旧理由仅用于保留历史记录，当前可选理由为 302 条。默认仍有 8 个核心情景，另外 5 个只在用户主动选择时逐题加入。

## 结果与参考

结果首先展示实际作答数量、各题判断边界、可接受修改、理由、未确定处与详细记录。默认“导出结果”生成可阅读的 Markdown；结构化 JSON 是另一个明确选项。

参考库只有在用户主动启用时加载。维护文件保留 75 项参考，默认产品比较只使用 36 项已独立整理的参考；16 项测试用假想参考和 23 项待独立整理条目不进入普通结果。用户记录完整度只依赖自己的记录，与某个参考双方有多少可比字段分别计算。不确定或资料缺失不作为相同立场的证据。

参考卡片按名称排列，说明来源、具体相同记录、差异与资料缺口，不显示立场优劣排名或身份概率。16 位指纹只用于校验可比较的已确认结构，不包含全部自由文本，不是人格类型。

## 数据边界

| 数据 | 保存位置 | 是否自动上传 |
| --- | --- | --- |
| 结构化进度、逐题检查点、已确认的未确定处 | 当前浏览器 `localStorage` | 否 |
| 未确认的自定义理由草稿 | 当前标签页 `sessionStorage` | 否 |
| AI 配置、密钥与完整 AI 消息 | 当前页面内存 | 否 |
| 正式题库 | 同源静态 JSON | 只读下载 |
| 参考 benchmark | 主动启用后从同源读取 | 否 |
| 0.9 旧进度 | 新进度内的只读 `legacyArchive` | 否 |

调用 AI 时，只把当前自定义理由、正在说明的命题及必要政策上下文发送给用户选择的模型服务商；候选必须由用户检查确认。原始 AI 对话不写入持久进度，AI 失败不改变已有判断。结果导出不包含密钥、配置、未确认草稿、浏览器 cookie 或 AI 原始消息。

## 版本与兼容

`public/bank/manifest.json` 当前加载 `model-1.3.0.json`；`ideology-benchmark-1.3.0.json` 延迟加载。原 1.2.2 模型与参考库保留原字节。四条修订理由使用新 ID，旧定义保留给旧答案，不自动升级为新检验。

1.0、1.1、1.2.0、1.2.2 的 v4 结构化进度保留来源版本并续答。旧顺序流程只恢复能够确定发生过的修改比较，不补造偏好或理由。专家暂停题的旧权限表述按来源版本保留，不自动解释为用户接受了新版明确的议会决定权。

0.9 的组件答案没有被接受的完整政策框架，因此只作只读归档，可以查看和导出，不参与现版问卷或比较。

## 本地开发

```bash
npm install
npx playwright install chromium
npm run test:release
npm run simulate:benchmark
npm run dev
```

`npm run prepare:model:1.3` 可从固定 1.2.2 原字节重复生成本版模型；只有维护这次内容迁移时才需要运行。正常构建直接校验已提交的现版 JSON，不静默修改题库。

## 主要目录

- `src/lib/decisionEngine.js`：完整方案判断、顺序诊断、理由核对、逐题检查点与摘要。
- `src/lib/formalValidator.js`：形式结构、未检验选择和实际修改记录的交叉校验。
- `src/lib/resultPresentation.js`：实际判断的普通语言展示与可读导出。
- `src/lib/entertainmentMatcher.js`：独立记录完整度、双方可比覆盖和参考资料边界。
- `src/hooks/useSession.js`：本地续答、版本来源与旧版保守迁移。
- `src/components/Questionnaire.jsx`、`ResultSummary.jsx`：逐题阅读与判断边界卡片。
- `public/bank/`：现版清单、模型、参考库、Schema 和只读历史文件。
- `tests/`、`scripts/test-ux-integrity.mjs`：浏览器验收和使用完整性回归。
- `shared/`、`worker/`：旧贡献契约的兼容归档边界，不作为现版前台提交入口。

领域边界见 `CONTEXT.md`，长期决策见 `docs/adr/0012-record-integrity-and-explicit-review-depth.md`，部署说明见 `docs/DEPLOY.md`。
