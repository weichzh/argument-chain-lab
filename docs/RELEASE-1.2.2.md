# 1.2.2：比较对象、相似案例与读者体验

应用、正式题库和娱乐基准均更新为 1.2.2。旧 1.2.0 文件原字节保留，manifest 仅加载新版；继续兼容 1.0、1.1、1.2.0 的结构化进度。13 项政策的维度、赋值、框架和 302 条理由内容没有变化。

## 本轮审阅与修正

通读了 13 项政策的固定条件、50 项修改的诊断说明与命题指代、71 项相似案例文字。这是内部语义和阅读审阅，不是独立用户研究或对全部理由的哲学、实证认证。

50 个局部相反命题现在从实际框架差异取出原有值，避免把“只允许民事责任”等修改后的安排误写成原方案。局部说明只记录哪些修改足以改变判断，不推断唯一动机。13 个最终反对说明只记录题库所列修改尚未改变判断，不再推断用户反对所有可能设计。

表达处罚、元数据收集题的可修改安排不再混入固定条件，但仍完整显示在原方案中。共同治理题明确：若保留否决权，其适用范围才受相应边界约束。多数道德题第三个修改补出“私域行为也不受自愿团体内部规则约束”的区别。

四处案例纠正原则与提问的强度或条件不一致：

- `n_hierarchical_authority`：有防滥用条件的职责协调，不等于等级本身要求服从。
- `v_hierarchical_order`：明确岗位和指挥关系的组织作用，不等于无法申诉的无条件服从。
- `n_sacred_public_order`：宗教规范进入国家强制需要说明理由和界限，不反过来断言神圣秩序足以强制所有人。
- `n_expertise_can_delay`：保留充分风险证据、短期期限和最终民主控制，不能泛化为专家优先。

另外两处重复描述改成具体教育改革和洪灾授权场景。案例页同时显示正在检验的原则。新完成记录保存当时的原则、场景和问题原文；旧版对这六个改写案例的回答，不冒充现版案例相似特征。

## 流程和阅读

更深理由的前提或判断依据被拒绝、被标为不确定时，主路径和相反路径都回到正在说明的原则，保留已确认前缀，允许换理由、暂停或自定义。此前相反路径会返回错误层级，下一次选择可能造成目标不匹配。

最终复核明确针对完整原方案；改判按钮写明接受或不接受完整原方案，避免由局部理由自动推出整包立场。影响不确定的选项明确暂时保留原判断。

修改题说明每次都与原方案相比、不叠加未接受的修改，可展开未改动安排和完整原方案。手机导航保留文字，作答后键盘焦点回到阅读起点。旧结果和历史快照保留来源版本，旧 AI 候选显示当时确认的原文，结构引用仍须正确。

## 验证与边界

`npm run test:release` 运行模型、契约、迁移、匹配和生产构建浏览器检查。新增契约检查覆盖 50 个完整修改、440 个拒绝或不确定后的返回分支，以及框架、理由不变的约束。浏览器套件为 28 项，增加了修改不叠加、上下文回看、反方返回、旧候选续答、手机标签和焦点、明确改判与案例原文保存。

发布仍须另行核对 Sites 终态和线上版本来源。75 项参考库中的 23 个候选名称没有升级为独立整理结果；新版公开贡献流程不在本次范围内。AI 成功路径使用受控模拟服务，不等于验证了所有真实服务商。
