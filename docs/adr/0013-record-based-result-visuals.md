# 用实际记录驱动结果可视化

## 决定

应用 1.3.1 沿用题库 1.3.0。可视化为读取层，不改变问卷状态机、计分权重、排名、来源版本或持久化结构。对应 Issue #1 / PR #2。

总览以情景为单位，区分接受原方案、接受修改、反对原方案、仍有待确定处、跳过、进行中和未开始。核心题和附加题分别计数。“已作答”包含明确选择不确定，不包含跳过和进行中。复核发生改判时，以最终判断归类，同时保留初始回答标记。

方案轨迹只表示作答时比较的次序，不画成不断累加的修正。每个修改都与完整原方案比较。未测试与旧版未记录分开，历史明确接受仍保留。方案文字使用来源版本的定义，尤其不能将旧版专家权限解释为新权限。

主要与相反理由使用独立分支。只有前提、判断对象和原则认可均有对应记录时，才能显示确认连接；保存、未检验、自填、适用性未定和撤回不生成确认连接。相似案例采用记录中的问题和回答，没有保存案例则明确留空。原始前提与案例仍可展开，不用图形替代可追溯文字。

参考矩阵逐情景比较初始判断、修改边界、第一条主要理由、停止点和反方影响。状态包括相同、不同、主题交集、资料不足和不能直接比较。缺失不算分歧；不同目标、撤回记录、修订后的旧框架不作同一对象的比较。反方影响只有针对同一对象且核对同一路径时才直接对照。矩阵不是另一个相似度分数，其解释逐字段接受校验。

## 交互与隐私

图形由语义 HTML 与 CSS 渲染，不增加图表依赖、AI 调用或联网请求。点击图形只改变组件内的阅读状态；续答仍调用原有受测动作。状态同时有文字、符号和形状，不能只凭颜色区分。参考单元格可用键盘操作，并通过实时说明区显示双方原文。

桌面双分支、窄屏纵向分支；参考矩阵在窄屏按情景拆行，不要求整页横向滚动。打印保留方案状态文字与符号。针对截图的局部采集可隐藏固定的全站头部，避免头部遮挡被截区域，但不得修改结果内容。

## 不做什么

不推断人格、真实政治身份或论证能力，不复制缺少样本支撑的人群分布和百分位。不将已选择的理由提升为已检验理由，不重新解释旧记录，不将缺失等同于反对。

## 验收

数据测试覆盖计数分母、改判、未知状态、历史框架、撤回、前提缺失和参考比较对象。浏览器测试覆盖窄屏、键盘、跳转、状态不变、版式放大、打印及自由文本安全；实际检查桌面和手机截图。截图只用可重建的合成测试样本，原始参考站结果及浏览器信息不提交仓库。
