# Domain Docs

工程技能探索代码前，应读取相关领域文档。

## 读取顺序

- 根目录存在 `CONTEXT.md` 时读取它。
- 根目录存在 `CONTEXT-MAP.md` 时，读取它指向的相关上下文。
- 阅读 `docs/adr/` 中与当前工作相关的 ADR。
- 文件不存在时静默继续，不提前要求创建。

## 当前布局

本仓库使用单一上下文布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

`CONTEXT.md` 保存领域词汇和边界；`docs/adr/` 保存长期架构决策。它们在实际形成领域术语或决策时再创建。

## 使用规则

输出、Issue、测试和代码使用 `CONTEXT.md` 已定义的领域术语。若工作与现有 ADR 冲突，必须明确指出，而不是静默覆盖。
