# 1.3.0：判断边界、续答与参考覆盖修复

本地修复验收通过；生产发布尚未完成。线上版本不能由本文件或本地构建推断。跟踪 Issue：#1。长期规则见 ADR 0012。

## 实际变更

逐题检查点替代含全部政策状态的回退快照。查看题目列表默认续答，已完成题可回看；重答需确认且可以取消。完成后的检查点及时更新，避免旧的未完成草稿覆盖新结果。

反方页面不再把待检验命题当成用户已经表达的判断。接受、全部拒绝、不确定和未测试的修改分别记录。修改中途不确定可选填原因并继续后面的修改；已接受修改只说明足够，不推断必要、最小或最佳。

所选理由可先记录为 `unchecked`，不伪造前提和案例通过，之后从原位置继续。不同意前提、不同意原则、认为原则不适用，保留为未确认尝试。修复公共参与、争议解决和元数据组合理由的衔接及文字问题。专家建议暂停明确由议会决定是否暂停。

用户记录完整度与双方可比覆盖拆开计算。普通比较只使用 36 项独立整理参考，39 项测试或待整理参考仅保留在维护库。双方不确定不作为肯定相似。参考卡片按名称排列，说明具体相同点、差异和来源；不输出身份标签结论或立场优劣排名。

结果先显示实际判断边界、小结和数量统计，再提供详细路径与可选参考。删除长串拼接称号，默认导出可读 Markdown，结构化 JSON 单列。移动端减少重复说明，关键固定条件与完整方案仍展开，增加阶段提示和焦点可见性。

## 验收结果

`npm run test:release` 整套通过：包括现有状态机、理由连续性、读者契约、14 个无效模型变体、形式校验、旧会话迁移、AI 与贡献边界测试，以及 28 组新增使用完整性回归（含补答不从记录计数中消失）；随后完成生产构建，37 项真实 Chromium 测试全部通过。

参考库结构和全部 975 条参考路径模拟通过，无流程阻塞和循环。内部模拟显式允许测试参考，不改变普通产品排除测试参考的边界。

浏览器验收覆盖 320、390、768、1280、1440 像素宽度。首题记录：

| 视口 | 首个答案顶部 | 文档宽度 | 文档高度 |
| --- | ---: | ---: | ---: |
| 390 × 844 | 841.73 px | 390 px | 1142 px |
| 1280 × 900 | 651.45 px | 1280 px | 930 px |

前次 390 像素审计为首个答案约 983 px、文档高 1288 px。现在仍需少量滚动，未声称所有答案能同时放进手机首屏；关键条件没有为压缩高度而被隐藏。

测试期间发现并修复一处样式级联回归：旧 `.workspace` 网格覆盖新布局，导致阶段提示占据大伸展行。修正选择器优先级后，重新运行整套测试，37 项通过，而非放宽阅读位置断言。

构建仍有第三方 AI 包 `provider-env` 的 `node:fs` 浏览器外部化提示，以及测试环境颜色变量警告。浏览器模拟 AI 成功/失败与隐私边界测试通过；没有声称逐个调用所有真实付费服务商。
