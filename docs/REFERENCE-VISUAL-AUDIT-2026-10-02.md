## 已直接观察到的视觉结构

正式结果含九张 SVG 图表：上方单独的综合左右位置图，下方八维卡片。桌面全页截图中八维按三列排成 3+3+2。综合图居中且更宽，形成明确的第一阅读层；每张维度卡片重复同一顺序：名称、解释、分布曲线、方向文字、分组百分位、最近群体说明。

默认叠加民主党、独立派、共和党三组半透明曲线，以一条醒目的个人位置竖线和 YOU 标记定位作答者。读者看到的是分布之间的重叠，不仅是三个均值。每张图两端都有普通语言的方向提示。总体与站内作答者在图例中另列；保存的 DOM 中对应切换控件默认 `aria-pressed=false`，三党默认 true。本轮没有把未实际操作的图例切换、手机布局或键盘体验说成已验证。

色彩、边框和排版较克制：浅暖色背景、细边框卡片、衬线的总标题与说明、窄体无衬线的维度标题。主要色彩集中在图表和个人位置标记，视觉重点落在信息本身。方法与可靠性说明置于九张结果图之后，而不是占据首屏。

保存的 SVG 采用 `viewBox="0 0 100 40"`，曲线、标记与文字百分位分别组织；实际图表是可扩展矢量元素，不是预制图片。九个 SVG 均标记 `aria-hidden=true`，因此配套文字结果尤为重要；未执行真实读屏器验收，不据此宣称完全无障碍。

## 对 argument-chain-lab 的实现启示

1. 学习总览—重复卡片—详情的层级，以及同一视觉语法反复使用，不能只把原文字换成带边框的段落。当前 1.3 的可信度修复不等于已完成同等水平的可视化。
2. 总览应从实际记录生成：哪些原方案接受、哪些仅接受修改、哪些未确定、哪些理由已检验。数量必须区分已答、跳过与未完成，不能把认真思考的深度变成政治能力分数。
3. 每个核心情景可以用紧凑的判断边界卡片表达：原方案判断 → 已测试修改 → 记录到的立场变化。拒绝、不确定、未测试、接受必须同时有文字和不同形态，不能只靠颜色。
4. 理由详情适合小型双分支路径：主要理由与认真考虑的反方并列，实线表示已经确认的连接，未检验、适用性受质疑、撤回必须有清楚文字。只在用户展开时显示完整前提和案例，避免默认大型关系图。
5. 参考比较要直观显示相同、不同、缺失和不可比的部分。没有真实协调样本就不能复制该站的人群分布曲线、群体百分位或身份概率。借用其视觉层级，不借用不存在的统计解释。

以上为本轮观察与后续设计约束，不是本轮已经新增的产品界面。
